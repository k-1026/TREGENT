# 19. "오늘도 수고한 나에게"…카톡 선물하기 거래액 20%는 '내돈내산'

| 항목 | 내용 |
|---|---|
| 제목 | "오늘도 수고한 나에게"…카톡 선물하기 거래액 20%는 '내돈내산' |
| 언론 | 머니투데이 (김평화 기자) |
| 날짜 | 2026-08-11 |
| URL | https://www.mt.co.kr/amp/tech/2026/08/11/2026081110161547815 |

| 구분 | 언론 (수치는 카카오 2Q26 실적발표를 옮김) |
| 관련 이슈 | 이슈 3 관계형 vs 검색·예약형 커머스 |

**요약 (우리 말로 정리)**
- 카카오가 2Q26 실적발표에서 선물하기 거래액 중 자기구매 비중을 처음 공개했다고 전했다.
- 자기구매 거래액 증가율이 선물하기 전체 증가율보다 훨씬 높았다.
- 카카오는 2024년부터 '포 미 위크', '나에게 선물' 탭, '내돈내산' 랭킹 등으로 자기구매를 키웠다.
- 기자는 선물은 생일·명절 같은 계기가 필요하지만 자기구매는 반복된다고 보면서, 자기구매만으로 커머스가 계속 클지는 지켜봐야 한다고 유보했다.

**핵심 수치 (2026년 2분기, 기사 기준)**
| 항목 | 수치 |
|---|---|
| 선물하기 거래액 중 자기구매 비중 | 약 20% |
| 선물하기 거래액 증가율 | +9% YoY |
| 자기구매 거래액 증가율 | +39% YoY (1Q26 +53%) |
| 톡비즈 커머스 매출 | 2,432억원 (+10% YoY, 직전 분기 대비 -10%) |

**짧은 인용:** "자기 구매 비중을 높이고" (정신아 대표, 2024년 11월 실적발표 발언으로 기사에 인용)

**주의:** 2Q26의 "약 20%"는 선물하기 거래액 기준이고, 3Q26 IR의 "30% 수준"은 새 기준(선물하기·톡스토어 합산) 커머스 거래액 기준이라 분모가 다르다 (우리 해석).
