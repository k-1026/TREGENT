# 23. 카카오, 러닝 축제 '카카오프렌즈 런 2026' 개최

|---|---|
| 제목 | 카카오, 러닝 축제 '카카오프렌즈 런 2026' 개최 |
| 기관 | 카카오 뉴스룸 보도자료 |
| 날짜 | 2026-08-04 |
| URL | https://www.kakaocorp.com/page/detail/12095 |

| 관련 항목 | 웰니스(운동) × 캐릭터 IP, IP → 캠페인 → 커머스 경로 |

**요약 (우리 말로 정리)**
- 카카오프렌즈 IP로 대규모 러닝 행사를 열었다. 기록 경쟁보다 즐기는 '펀 런' 방식이다.
- 참가 신청을 공식 홈페이지와 카카오톡 선물하기 기획전에서 받았다 (행사 참가권이 커머스 상품이 됨).
- 채널을 추가하면 러닝 콘셉트 이모티콘을 무료로 줬고, 기념품은 ARC와 협업한 러닝 의류 세트·완주 메달이다.
- 카카오같이가치 기부, 카카오맵, 카카오톡 지갑, AI 인증샷 등 자사 서비스를 묶었다.
- 외부 브랜드 28개사가 참여했지만 지자체·공공 보건기관 협업은 보도자료에 없다.

**핵심 수치**
| 항목 | 수치 |
|---|---|
| 일시·장소 | 2026-10-10, 경기 성남시 탄천 일대 |
| 규모 | 약 1만 명, 5km·10km |
| 참가비 | 8만원 |
| 신청 기간 | 2026-08-10 ~ 08-17 (추첨) |
| 참여 브랜드 / 체험 부스 | 28개사 / 약 30개 |

**짧은 인용:** "카카오프렌즈 IP와 함께 뛰는 즐거운 경험을 선사할 계획" (카카오 관계자)

**주의:** 실제 행사 결과(참가 인원, 매출)는 확인하지 않았다.
