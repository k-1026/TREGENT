# 26. 용인특례시, 조아용 3D 이모티콘 27만명분 무료 배포

| 항목 | 내용 |
|---|---|
| 제목 | 용인특례시, 조아용 3D 이모티콘 27만명분 무료 배포 |
| 언론 | 데일리안 (유진상 기자) |
| 날짜 | 2026-08-03 |
| URL | https://www.dailian.co.kr/news/view/1673980/ |
| 접속일 | 2026-11-06 |
| 구분 | 언론 (시 발표를 옮김) |
| 관련 항목 | 지역 캐릭터 × 카카오톡 |

**요약 (우리 말로 정리)**
- 용인시가 캐릭터 '조아용' 3D 이모티콘을 카카오톡 채널로 대규모 무료 배포했다.
- 기존 채널 친구와 당일 '용인시' 채널을 추가한 이용자가 받을 수 있다.
- 2025년 배포 때는 28분 만에 소진됐다고 시가 밝혔다.
- 굿즈·상품 연계는 기사에 없다.

**핵심 수치**
| 항목 | 수치 |
|---|---|
| 배포 수량 | 27만명분 |
| 이모티콘 | 16종 ('조아용의 T나는 모먼트') |
| 시작 | 2026-08-07 오후 2시 |
| 사용 기한 | 내려받은 뒤 30일 |
| 2025년 배포 소진 시간 | 28분 |

**짧은 인용:** "조아용은 지방자치단체 캐릭터의 한계를 벗어나" (이상일 용인시장)

**주의:** 검색 요약에는 "15분 만에 25만건 소진"이라는 다른 수치가 보였으나 원문에서 확인하지 못해 쓰지 않았다.
