# 도달쑤 브랜드 포지셔닝 아이디어

2026년 11월 4일 기준 · 박민지

> 목적: 도달쑤를 어떤 캐릭터로 자리 잡게 할지 포지셔닝 아이디어를 내고 비교합니다. 이 아이디어가 에이전트(캐릭터 생성, 설정, 관광지 추천, 굿즈 도안) 기획에 어떻게 이어지는지도 예시로 붙였습니다.
> 아이디어는 모두 **제안**이며 팀 논의로 고릅니다.

## 핵심 요약

- **출발점:** 도달쑤는 생김새는 확실하지만 성격과 스토리가 비어 있습니다. 수달은 진주 하모와 겹치고, 생태 메시지는 수성구 뚜비가 먼저 차지했습니다. 따라서 **소재(수달)가 아니라 역할과 성격으로** 차별화해야 합니다.
- **아이디어 8개**를 냈습니다. 골목 토박이 친구, 골목 알바 수달, 대프리카 생존 수달, 10미 먹방 탐험가, 고향 연락책, 동네 리포터, 대구 응원단장, 근대골목 시간여행자입니다.
- **추천 조합:** 메인은 **② 골목 알바 수달**(베리에이션 구조)과 **① 골목 토박이 친구**(성격·말투)입니다. 시즌용으로 **③ 대프리카**(여름)와 **⑤ 고향 연락책**(명절)을 더합니다.
- 이 조합이면 "북성로 공구골목 도달쑤" 같은 베리에이션이 그때그때 만든 그림이 아니라, **"골목마다 알바하는 같은 친구"라는 하나의 세계관**으로 묶입니다.

## 2. 포지셔닝 아이디어 8개

### ① 골목 토박이 친구

> "니 여기 아나? 내 단골이다." 대구 골목을 다 꿰고 있는 고향 친구.

| 항목 | 내용 |
| --- | --- |
| 대상 | 대구 2030, 출향민 |
| 성격·말투 | 정 많음, 오지랖, 먹는 거 진심. 가벼운 대구 사투리 반말 |
| 차별점 | 관광 안내원이 아니라 친구 시점. 하모·뚜비에 없는 "로컬 인싸" 역할 |
| 에이전트 예시 | 생성: 단골집 앞에서 음식을 내미는 장면 · 설정: "친구를 단골집에 데려가는" 에피소드 · 추천: "내 단골" 말투로 골목 추천 · 굿즈: "마이 무라~" 말풍선 스티커 |
| 위험 | 사투리가 어색하면 역효과. 대구 출신 검수 필요 |

### ② 골목 알바 수달 (골목마다 일하는 수달)

> 신천에서 올라온 도달쑤가 대구 골목마다 알바를 하며 일을 배운다. 골목이 바뀌면 직업과 옷이 바뀐다.

| 항목 | 내용 |
| --- | --- |
| 대상 | 숏폼·인스타툰 구독자, 골목 상인 |
| 성격·말투 | 서툴지만 성실한 막내. 실수해도 웃는 "열정 알바생" |
| 차별점 | **베리에이션 자체가 세계관이 됨.** 골목 하나가 캐릭터 하나 + 에피소드 하나 |
| 베리에이션 예 | 북성로 공구골목 견습공(작업복, 목장갑) · 서문시장 호떡 알바 · 약령시 한약방 견습(약재 서랍) · 칠성시장 과일가게 · 평화시장 닭똥집 골목 · 안지랑 곱창 골목 · 동성로 버스커 |
| 에이전트 예시 | 생성: "골목 이름 → 직업 의상" 규칙 · 설정: 알바 첫날, 실수, 단골 생김 순서의 에피소드 틀 · 추천: "내 알바한 데 가 볼래?" · 굿즈: 알바 명찰 키링, 골목별 컬렉션 카드 |
| 위험 | 노동 미화로 보이지 않게, 실제 상인을 놀리지 않게 표현 |

### ③ 대프리카 생존 수달

> 덥다고 매일 투덜대지만 대구 여름만큼은 누구보다 잘 노는 수달.

| 항목 | 내용 |
| --- | --- |
| 대상 | 전국 2030 (대프리카 밈을 아는 사람) |
| 성격·말투 | 투덜이지만 미워할 수 없는 성격. "덥제? 그래도 이 맛에 산다 아이가" |
| 차별점 | 대구만의 공감 밈. 다른 도시가 따라 하기 어려움 |
| 에이전트 예시 | 생성: 녹아내리는 아이스크림, 신천 물놀이 · 설정: 폭염 생존 시리즈 · 추천: 실내·야간·물가 명소 추천 · 굿즈: 부채, 손풍기, 쿨토시 |
| 위험 | 시즌(여름)에 몰림. 메인보다 시즌 콘셉트로 적합 |

### ④ 10미 먹방 탐험가

> 대구 10미를 다 먹어 보는 게 인생 목표인 먹보 수달.

| 항목 | 내용 |
| --- | --- |
| 대상 | 미식 여행객, 먹방 숏폼 시청자 |
| 성격·말투 | 먹는 거 진심. 맛 표현이 과한 리액션형 |
| 차별점 | 대구10미 캐릭터(음식별 10종)를 **한 얼굴로 묶음** |
| 에이전트 예시 | 생성: 기존 10미 콜라보 그림처럼 음식 의상 · 설정: 10미 도장깨기 에피소드 · 추천: 10미 맛집 + 대중교통 코스 · 굿즈: 10미 스탬프북, 음식 의상 키링 10종 |
| 위험 | 실제 식당 홍보로 비치지 않게 특정 업소 노출 기준이 필요 |

### ⑤ 고향 연락책

> 대구를 떠난 사람들에게 "요즘 대구는 이래" 하고 소식을 전해 주는 고향 친구.

| 항목 | 내용 |
| --- | --- |
| 대상 | 수도권 등에 사는 대구 출향민 |
| 성격·말투 | 다정한 잔소리꾼. "밥은 묵고 다니나?" |
| 차별점 | 관광보다 향수를 겨냥. 기존 설·추석 무료 이모티콘(2020년~)과 바로 연결됨 |
| 에이전트 예시 | 생성: 택배 상자, 기차역 배웅 장면 · 설정: 명절 귀향 에피소드 · 추천: "이번 명절에 들러 볼 데" · 굿즈: 엽서, 명절 이모티콘 |
| 위험 | 대상이 좁아 단독 메인으로는 약함 |

### ⑥ 동네 리포터 도달쑤

> 대구 동네 소식을 발로 뛰며 전하는 수달 기자.

| 항목 | 내용 |
| --- | --- |
| 대상 | 대구 시민, SNS 구독자 |
| 성격·말투 | 호기심 많고 수다스러움. "현장 나와 있습니다!" |
| 차별점 | 시정 홍보를 자연스러운 "취재" 형식으로 바꿀 수 있음 |
| 에이전트 예시 | 생성: 마이크를 든 현장 리포트 장면 · 설정: 주간 동네 소식 에피소드 · 추천: "이번 주 취재지" · 굿즈: 기자 수첩, 마이크 키링 |
| 위험 | 시정 홍보 톤이 강해지면 재미가 떨어짐 |

### ⑦ 대구 응원단장

> 삼성 라이온즈, 대구FC, 국제대회까지 대구 경기라면 어디든 나타나는 응원 수달.

| 항목 | 내용 |

| 위험 | 구단 상표권 협의가 필요. 대회가 끝나면 이야기가 끊김 |

### ⑧ 근대골목 시간여행자

| 에이전트 예시 | 생성: 근대 복장 베리에이션 · 설정: 시대별 에피소드 · 추천: 근대골목 투어 코스 · 굿즈: 레트로 엽서, 우표 스티커 |

**한 문장 포지셔닝 (제안):**
> 신천에서 올라온 수달 도달쑤가 대구 골목마다 알바하며 단골집을 늘려 간다. 대구 2030과 출향민에게는 "골목을 다 꿰고 있는 토박이 친구"다.

## 5. 에이전트 기획 연결 (예시)

추천 조합을 팀이 기획한 4개 에이전트에 적용하면 이렇게 됩니다. 구현이 아니라 기획 참고용입니다.

| # | 에이전트 | 입력 예 | 포지셔닝 반영 결과 예 |
| :---: | --- | --- | --- |
| 1 | 캐릭터 생성 | "북성로 공구골목" | 얼굴은 그대로 두고 작업복, 목장갑, 공구 무늬 앞치마를 입힘. 배경은 공구 가게 골목 |
| 2 | 캐릭터 설정 | 위 베리에이션 | 이름: 공구골목 견습 도달쑤 · 특성: 손재주 없지만 열정 만렙 · 에피소드: 알바 첫날 나사를 잃어버려 사장님과 골목을 뒤지다 단골 가게를 알게 됨 |
| 3 | 관광지 추천 | 성향 테스트 "손으로 만드는 걸 좋아함" | 공구골목 도달쑤가 "니 이런 거 좋아하제? 내 알바하는 데 와 봐라" 하며 북성로와 주변 코스를 대중교통 경로와 함께 추천 |
| 4 | 굿즈 도안 | 키링, 스티커 | 알바 명찰 키링("북성로 공구골목 견습"), 골목별 수집 카드 시리즈 |
| (선택) | 웹페이지 | — | "도달쑤 알바 지도": 골목을 누르면 그 골목 도달쑤와 에피소드가 나옴 |

### 5-1. 모든 에이전트가 공유할 기준

1. 포지셔닝 문장 (4장)
2. 성격 키워드와 말투 예시, 금지 말투 (욕설, 지역 비하, 정치 표현)
3. 고정 생김새: 얼굴, 색, 비율. 바뀌는 것은 의상, 소품, 동작, 배경
4. 금지 요소: 다른 도시 상징, "공식 마스코트" 표현, 시 로고, 실존 인물
5. 베리에이션 규칙: 골목 이름 → 직업과 의상 → 에피소드 한 개

## 6. 남은 확인

- **팀 선택:** 8개 중 메인과 시즌 콘셉트를 확정합니다.
- **사투리 검수:** 대구 출신 팀원이나 지역 창작자에게 확인합니다.
- **대구시 확인:** 공식 지위와 상업적 이용 가능 여부(2022년 기준으로는 수익 사업 불허)를 확인합니다.
- **반응 테스트:** 아이디어 2~3개로 시안을 만들어 숏폼이나 인스타툰으로 올리고, 저장·공유 수를 비교합니다.
