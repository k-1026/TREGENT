# 🎨 소품·배경 에셋 넣는 법

그림 파일을 아래 폴더에 넣기만 하면 바로 쓰여요. 서버를 다시 켤 필요도 없어요.
**파일 이름이 곧 에셋 이름**이라, `씨앗호떡.png`처럼 무엇인지 알 수 있는 한국어 이름으로 저장해 주세요.

| 폴더 | 들어갈 것 | 놓이는 자리 | 배경 |
|---|---|---|---|
| `background/` | 서문시장 배경 | 캔버스 전체 (세로 그림 권장) | 꽉 찬 그림 |
| `hand/` | 손에 드는 소품 | 왼손 또는 오른손 | **투명** |
| `head/` | 모자·머리띠·머리 장식 | 머리 위 | **투명** |
| `neck/` | 목도리·스카프·목걸이 | 목 | **투명** |
| `body/` | 앞치마·조끼 | 몸 앞 | **투명** |
| `back/` | 망토·큰 원단 | 등 뒤 | **투명** |
| `ground/` | 장바구니 등 바닥에 놓는 것 | 발 옆 | **투명** |

- 형식은 PNG(권장), WEBP, JPG를 쓸 수 있어요. 배경을 뺀 소품은 **투명 배경 PNG**여야 자연스러워요.
- 그림 둘레의 투명한 여백은 자동으로 잘라내니, 소품 하나만 가운데 있으면 돼요.
- 공구류(렌치, 볼트 등) 이름의 파일은 자동으로 빠져요.
- 도달쑤 얼굴(눈·코·수염·입)은 어떤 소품도 덮지 못하게 막혀 있어요.

## ChatGPT로 에셋 만들기 (무료)

ChatGPT 웹에서 아래 **공통 문장 + 소품 문장**을 붙여 넣으면 돼요.
여러 개를 만들 때는 한 대화창에서 이어서 만들어야 그림체가 비슷하게 유지돼요.

**공통 문장 (소품용)**
```
귀여운 2D 마스코트 스티커 스타일의 소품 일러스트 하나만 그려줘.
굵고 깔끔한 검은 외곽선, 그라데이션 없는 단색 면, 따뜻하고 밝은 색.
캐릭터나 손은 그리지 말고 물건 하나만, 정면, 화면 가운데.
글자 없음. 배경은 투명(transparent PNG).
```

**공통 문장 (배경용)**
```
귀여운 2D 마스코트 일러스트용 배경을 세로 비율(5:6)로 그려줘.
굵고 깔끔한 검은 외곽선, 그라데이션 없는 단색 면, 따뜻하고 밝은 색.
사람이나 캐릭터는 없이, 가운데 아래쪽은 캐릭터가 설 수 있게 비워 둬.
간판에 글자는 쓰지 마.
```
