# 🖼️ 관광지 배경 만들기 (ChatGPT 웹, 무료)

ChatGPT 웹에 **공통 문장 + 관광지 문장**을 붙여 넣어 그림을 만든 뒤,
**표에 적힌 파일 이름 그대로** 이 폴더(`agent/assets/backgrounds/`)에 저장하면 끝이에요.
서버를 다시 켤 필요 없이 다음 생성부터 바로 쓰여요.

- 같은 이름의 `.svg`(일러스트)가 있어도, `.png`·`.jpg`·`.webp`를 넣으면 그쪽이 먼저 쓰여요.
- 무료 계정은 하루에 만들 수 있는 그림 수가 정해져 있어서, 며칠에 나눠 만들어도 돼요.
- 여러 장을 한 대화창에서 이어서 만들면 분위기가 비슷하게 맞춰져요.

## 1. 공통 문장 (매번 맨 앞에 붙이기)

둘 중 원하는 분위기 하나를 골라 쓰세요.

**사진풍 (AI 골목 이미지 느낌)**
```
세로 그림(가로:세로 = 5:6)으로 아래 장소의 배경 이미지를 만들어줘.
밝고 따뜻한 색감의 고퀄리티 사진풍 풍경, 약간 부드럽게 흐린 배경 느낌.
사람, 캐릭터, 동물은 없이 풍경만. 간판이나 표지판에 글자는 넣지 마.
가운데 아래쪽은 캐릭터가 설 자리라 비교적 비워 두고, 바닥이 보이게 해줘.
```

**일러스트풍 (도달쑤 그림체와 맞춤)**
```
세로 그림(가로:세로 = 5:6)으로 아래 장소의 배경 일러스트를 만들어줘.
귀여운 2D 마스코트 배경 스타일, 굵고 깔끔한 검은 외곽선, 그라데이션 없는 단색 면, 밝고 따뜻한 색.
사람, 캐릭터, 동물은 없이 풍경만. 간판이나 표지판에 글자는 넣지 마.
가운데 아래쪽은 캐릭터가 설 자리라 비교적 비워 두고, 바닥이 보이게 해줘.
```

## 3. 저장하는 법

1. ChatGPT에서 그림이 나오면 그림 위 **다운로드 버튼**으로 내려받아요.
2. 내려받은 파일 이름을 표의 **파일 이름**으로 바꿔요. 예: `수성못.png`
3. 이 폴더(`agent/assets/backgrounds/`)에 넣으면 끝!

> ⚠️ 관광지 이름(파일 이름)은 띄어쓰기와 기호(`·`)까지 표와 똑같아야 해요.
