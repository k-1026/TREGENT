# 🦦 도달쑤 × 대구 관광지 그림 에이전트

대구 관광지와 장면을 글로 적으면, **원형 도달쑤**(`images/dodalssu-basic.png`)가 그곳을 즐기는 그림을 만들어 줍니다.
관광지를 적지 않으면 서문시장으로 그려요.

## 동작 순서

1. **Gemini**(무료 글 모델)가 입력 글을 읽고 **관광지, 포즈, 소품**을 고릅니다. 공구류는 뺍니다.
2. 미리 만들어 둔 그림을 정해진 자리에 합성합니다.
   - **도달쑤**: 얼굴·머리·몸·다리는 원형 픽셀 그대로이고, 포즈에 따라 **팔만** 바뀝니다. 소품은 얼굴을 덮지 못하게 막혀 있어요.
   - **포즈** (`poses/`): 기본, 한 손 들기, 두 손 모아 들기, 손 흔들기
   - **배경** (`assets/backgrounds/`): 서문시장, 수성못, 김광석다시그리기길
   - **소품** (`assets/props/`): 씨앗호떡, 납작만두, 칼국수, 어묵꼬치, 아이스크림, 풍선, 하모니카, 카메라, 통기타, 장바구니, 한복천 스카프, 오리배 머리띠, 베레모
3. 배경이 준비되지 않은 관광지는 Gemini가 배경을 직접 그려요. 이 경우 품질이 낮고 화면에 표시돼요.

### 배경을 AI 이미지(사진풍)로 바꾸기

`assets/backgrounds/<관광지 이름>.png` (또는 `.jpg`, `.webp`)를 넣으면 같은 이름의 일러스트(`.svg`)보다 먼저 쓰여요.
예: `assets/backgrounds/수성못.jpg`. 세로 비율(약 5:6) 그림이 잘 맞고, 가운데 아래쪽은 도달쑤가 서는 자리라 비어 있는 게 좋아요.
관광지 이름은 [`prompts.py`](prompts.py)의 `DAEGU_SPOTS`와 같게 적어 주세요. 새 관광지 이름으로 넣으면 그 관광지도 준비된 배경으로 쓰여요.

### 포즈·소품 손보기

- 포즈 좌표를 바꾸면 `python tools/build_poses.py`로 포즈 그림을 다시 만듭니다.
- 소품을 추가하려면 `assets/props/`에 SVG를 넣고 [`prompts.py`](prompts.py)의 `PROPS`에 이름·자리·크기를 적어요.

## 실행

1. Python 3.10 이상을 설치합니다.
2. `agent` 폴더에서 패키지를 설치합니다.
   ```bash
   pip install -r requirements.txt
   ```
3. `.env.example`을 `.env`로 복사하고 `GEMINI_API_KEY`를 채웁니다. 키는 aistudio.google.com에서 발급합니다.
   - 모델이 붐비거나(503) 한도를 넘으면(429) `.env`의 모델 목록에서 다음 모델로 자동으로 넘어갑니다.
4. 서버를 켭니다.
   ```bash
   python -m uvicorn main:app --port 8000
   ```
5. 브라우저에서 http://localhost:8000 을 엽니다.

결과 그림은 `agent/outputs/`에 SVG로 저장되고, 화면에서 PNG로 내려받을 수 있어요.
