# 대구 캐릭터 콘텐츠 기획 보고서

기준일: 2026년 11월 4일 · 1104 발표 이후 논의한 내용을 하나로 연결한 문서

**표기**
- `발표` = 지자체·제작사 자체 수치
- `미검증` = 검색 요약이나 출처 불명 수치
- `추론` = 우리 해석

---

## 0. 한눈에 보는 논리

1. **문제:** 도달쑤는 쓰이고 있지만 개성과 이야기가 약하다.
2. **원인:** 지역 캐릭터는 예쁜 그림만으로 뜨지 않는다. 이름, 활동, 판매 동선, 지속성이 함께 필요하다.
3. **차별화:** 인기 작품은 귀여움이 아니라 **귀여움과 충돌하는 현실**, **결핍**, **관계**로 구별된다.
4. **콘셉트:** 그래서 대구의 더위·시장·무뚝뚝한 정을 일터 시트콤으로 푼다. → **「도달쑤 일일 알바」(가제)**
5. **인물:** 시트콤은 관계로 굴러가므로, 설정표보다 관계를 먼저 만든다. 구별 캐릭터는 회차의 사장님·단골로 출연시키고, 인지도가 쌓이면 연합으로 모은다.
6. **장면 이미지 제작:** 매회 같은 얼굴과 안정된 표정이 필요하다. → 사람이 만든 파츠를 AI가 조합
7. **유통:** 흔한 심리테스트 대신 → 알바 면접 → 일터 배치 → 코스 → 현장 방문 → 굿즈로 잇는다.
8. **실행:** 위 내용을 반영해 기존 4단계 에이전트를 재설계한다. (12장)

> 핵심 문장: **"대구에서 일하는 건 덥고 억울한데, 사장님이 결국 밥은 챙겨 준다."**

## 1. 출발점: 도달쑤의 문제

**현재 상태**
- 대구시 대표 캐릭터로 쓰이지만, 공식 지정 문서는 찾지 못함 (2022년 시 입장은 "공식 아님")
- 2022년 기준 전담 2명, 수익사업 불허
- 전문가 비판: 개성과 스토리 부족, 계획 아래 만든 캐릭터가 아님

**비교로 보이는 격차 (간접 비교)**
- 2021년 이모티콘 배포: 하모 5만 개 13분 vs 달쑤 4.5만 개 1시간 30분

**→ 따라서** 질문은 "새 그림을 어떻게 만들까"가 아니라 **"사람들이 왜 좋아하게 만들까"** 이다. 2장에서 지역 사례를, 3장에서 인기 작품을 본다.

## 2. 지역 캐릭터는 어떻게 떴나

### 사례별 분석

**대전 꿈돌이: 향수 + 먹거리 + 관광 동선**
- 배경: 1993 엑스포 마스코트, 이후 오랜 공백
- 방식: 2023 꿈씨 패밀리 확장, 웹툰 12부작, 대전역 매장, 지역 기업 협업 라면·호두과자
- 반응: 협업 상품 약 23억 원(6개월), 라면 110만 개 `발표`, 역 매장 후 월 판매액 약 19배 `발표`
- 한계: 증가세 둔화, 민선 9기 방향 미정, 세계관 피로 우려

**진주 하모: 이름에서 지역이 보이고, 받기 쉽다**
- 배경: 2021년 등장, 남강·진양호 수달
- 특징: 이름은 진주 방언 "하모", 진주 목걸이와 물결 꼬리
- 방식: 한정 이모티콘·인형 무료 배포 → 판매 요청이 나오자 전시·이벤트 연장
- 반응: 5만 개 13분 소진, 카카오 채널 약 6천→5만 명 `발표`
- 한계: 매출 미확인

**고양 고양고양이: 한 번의 장난이 정체성이 됨**
- 배경: 2012년 시 SNS 프로필을 고양이 그림으로 바꾸자 커뮤니티 확산 (988 리트윗)
- 특징: 지역명 말장난, 말투 있는 SNS 운영
- 반응: 사용 중단 후 폐지 반대 민원, 2026년 7월 복귀 환영, 복귀 영상 2개월 260만 회 `발표`
- 한계: 시장 교체기에 약 3~4년 중단, 굿즈·수익 미확인, 중단 사유는 비판 보도뿐 (전임 시장 측 입장 미확인)

**구마모토 구마몬: 위기에서 시작한 "일하는" 캐릭터**
- 배경: 규슈 신칸센 개통 때 지역이 지나쳐질 위기
- 방식: 오사카 곳곳에 깜짝 출현, 명함 1만 장 배포, 현 영업부장 직함, 국내 무상 허가제
- 반응: 2년 경제파급효과 1,244억 엔(일본은행 지점 추정), 2025 관련 상품 약 1,503억 엔
- 한계: 2년 연속 감소, 민간 매출 총액이라 현 수입이 아님, 식품 비중 76%(2023)

### 공통 조건 (`추론`)

- **이름·모티브:** 들으면 지역이 떠오른다 (하모, 고양고양이)
- **활동:** 캐릭터가 말하고 일한다 (영업부장, 고양이 말투)
- **낮은 문턱:** 무료 이모티콘, 무상 허가, 저렴한 식품
- **기존 동선:** 사람이 오는 곳에서 판다 (대전역 매장)
- **시민 애착과 지속성:** 애착이 있어도 시장이 바뀌면 끊길 수 있다 (고양)

**→ 그러나** 이 조건은 "어떻게 퍼뜨릴까"를 설명할 뿐, "왜 이 캐릭터를 좋아할까"는 충분히 설명하지 못한다. 그래서 인기 작품을 본다.

## 3. 인기 작품은 무엇이 달랐나

### 3-1. 작품별 차별점

**치이카와**
- 캐릭터: 약하고 잘 우는 주인공, 말보다 "이야!" 같은 반응이 먼저
- 세계관: 동화 같은 숲에 **풀 뽑기 검정, 토벌 순위, 자격 등급**이 있음
- 스토리: 평화로운 일상 → 괴물, 실패하면 죽을 수 있는 위협, 친구였던 존재의 변이
- 차별점: 귀여운 외형과 노동·격차·불안의 충돌
- 작가 발언: 메시지보다 "일이 벌어졌을 때의 반응과 표정"을 그리고 싶다
- 형식: X의 1쪽 연재 → 애니메이션, 영화

**어그레시브 레츠코**
- 캐릭터: 얌전한 레서판다 회사원, 퇴근 후 데스메탈 노래방에서 폭발
- 세계관: 동물 캐릭터로 그린 현실적인 회사 문화
- 스토리: 직장 스트레스에서 후기 시즌 정리해고까지 확장
- 차별점: 산리오가 만든 귀여움과 분노의 대비

**리락쿠마**
- 캐릭터: 어느 집에 불쑥 눌러앉아 빈둥거리는 곰 인형, 등의 지퍼 속은 비밀
- 세계관: 사건 없는 평범한 집
- 스토리: 큰 갈등 없는 느린 일상
- 차별점: "노력하지 않아도 되는" 허락, 지퍼라는 작은 수수께끼

**잔망루피**
- 캐릭터: 다정한 조연 루피가 밈에서 사악한 표정과 험한 말로 반전
- 세계관: "직장 일기" 등 직장인 정체성이 추가됨
- 스토리: 순수했던 루피가 회사 생활로 날카로워졌다는 전제
- 차별점: 팬의 패러디를 권리사가 공식으로 받아들임
- 형식: 중학생이 올린 이미지(2019) → 공식 IP

**브레드이발소**
- 캐릭터: 천재 식빵 이발사와 조수 윌크, 외모가 고민인 빵 손님
- 세계관: 빵집 1층과 빵들이 사는 2층 창고 마을, 한국 직장인 문화 반영
- 스토리: 고민 있는 손님이 오는 반복 구조에 패러디, 현실 풍자
- 차별점: 한국 빵의 화려함을 설정의 출발점으로 삼음
- 교훈: 시즌 1의 거친 풍자에 항의가 있어 시즌 2에서 덜어냄 `발표`

**가나디**
- 캐릭터: 그리다 만 듯한 흰 강아지, 이름도 강아지를 부르는 귀여운 말
- 세계관: 복잡한 서사보다 짤 중심
- 차별점: 대화에서 바로 쓸 수 있는 활용성 (X 1~2만 리트윗 → 이모티콘 1위) `미검증`

**꺅두기**
- 캐릭터: 흑백 선, 튀어나온 입, 슬픈 눈
- 스토리: 서사 대신 짤과 이모티콘
- 차별점: 위로하는 쪽이 아니라 **희로애락을 겪는 쪽**이라 팬이 응원함
- 관계: 인플루언서 닥터후와 놀리고 반응하는 모습이 서사처럼 소비됨

**틴틴팅클**
- 캐릭터: 고양이 초등학생들, 이혼·입양·가난·돌봄 부담 같은 사정이 있음
- 세계관: 90년대생의 어린 시절, 제목도 옛 과자 이름
- 스토리: 회차마다 한 인물의 사정을 보여 줌 (콩물이 편, 자매 화해 편)
- 차별점: 귀여운 그림으로 현실 가정사를 진지하게 다룸. 독자가 자신과 닮은 인물을 찾음
- 시작: 반려묘 다툼 공감툰 → 독자가 이름을 물어봄 → 서사 확장

**농담곰**
- 캐릭터: 원래 이름이 "스스로 츳코미하는 곰", 자기 말에 자기가 딴지를 검
- 세계관: 먹방 중심의 일상
- 차별점: **혼자서도 만담이 되는 구조**, 볼록한 볼과 먹는 모습이라는 표식

### 3-2. 추가로 참고할 IP

- **스미코구라시:** 구석을 좋아하고 콤플렉스가 있는 캐릭터들, 남겨진 튀김 꼬리 같은 설정, 목소리를 넣지 않는 원칙 → 결핍 설계의 모범
- **펭수:** 10살, 키 210cm, 소품실 거주, 연습생, 꿈은 "우주 대스타" → 구체적 프로필, 상사에게 할 말을 하는 대리 만족
- **망그러진곰:** 이모티콘 → 인스타툰 → 두산베어스 협업 → 팬덤명 "부앙단" → 지역 구단과 협업하는 참고 사례
- **마루는 강쥐:** 웹툰 완결 후 유튜브 → 넷플릭스 키즈 1위 → 작품이 끝나도 캐릭터는 남음
- **버터베어:** 태국 **지역 카페 홍보용**(2023)에서 춤 영상으로 확산 → 로컬 가게 캐릭터의 참고 사례
- **찌그러진 누룽쥐:** 팬 사연에 반응, 퇴사 위기 사연에 몽둥이로 회사를 때림 → 팬과 함께 만드는 짧은 콘텐츠
- **한컴타자 캐릭터:** 이름 없는 "갈색머리 걔"가 인기투표 1위, 바디필로우 출시 → 조연 역전의 사례
- **라부부:** 서사보다 가방에 다는 사용 방식이 반복 구매를 만들었다는 분석 → 굿즈는 이야기와 별개로 설계해야 함

### 3-3. 차별화 원리 6가지 (`추론`)

1. **겉과 속의 충돌**
   - 귀여운 외형 × 고된 현실
   - 예: 치이카와의 노동, 레츠코의 메탈, 루피의 험한 말
2. **결핍이 곧 정체성**
   - 강점보다 약점으로 기억됨
   - 예: 스미코구라시의 콤플렉스, 꺅두기의 슬픈 눈, 브레드이발소 손님의 외모 고민
3. **현실 제도를 세계관에 넣기**
   - 판타지보다 아는 제도가 웃기고 아프다
   - 예: 풀 뽑기 검정, 펭수의 연습생, 빵 세계의 직장
4. **비워 두기**
   - 다 설명하지 않아 해석과 활용이 생김
   - 예: 리락쿠마의 지퍼, 치이카와의 적은 대사, 가나디의 미완성 같은 그림
5. **관계가 이야기를 만든다**
   - 인물 사이의 긴장이 소재를 낳음
   - 예: 틴틴이와 팅클이의 다툼, 농담곰의 자기 츳코미, 꺅두기와 닥터후
6. **팬에게 넘기기**
   - 만들어 준 것보다 함께 만든 것에 애착이 감
   - 예: 잔망루피 패러디 수용, 틴틴팅클 이름 질문, 한컴타자 인기투표

**→ 따라서** "대구 소품을 든 귀여운 수달"은 이 중 어느 것에도 해당하지 않는다. 대구에서 충돌과 결핍, 관계를 찾아야 한다.

## 4. 대구로 옮기기: 장르와 콘셉트

### 왜 일터 시트콤인가

- **시장·골목이 곧 일터:** 서문시장, 북성로, 약령시는 이미 대구의 소재다
- **반복 구조:** 브레드이발소처럼 매회 새 가게·손님으로 확장할 수 있다
- **제작 부담:** 짧은 컷 중심이라 장편 3D 애니메이션보다 현실적이다
- **기존 기획과 연결:** 장소 = 회차 = 성지순례 코스 = 굿즈 소재

### 원리를 대구에 적용한 모습

| 원리 | 대구 적용 | 예시 |
|---|---|---|
| 겉과 속의 충돌 | 귀여운 수달 × 대프리카 노동 | 불판 앞에서 녹아내리는 도달쑤 |
| 결핍 | 눈치 없고 일 못 하는 신입 | 납작만두를 납작하게 못 뒤집음 |
| 현실 제도 | 시장의 규칙을 등급으로 | "단골 검정", "더위 경보 3단계" |
| 비워 두기 | 말수 적은 사장님, 정체불명 단골 | 늘 등만 보이는 약령시 사장님 |
| 관계 | 무뚝뚝한 사장님 × 억울한 신입 | "됐다 마" 하면서 밥 한 그릇 |
| 팬 참여 | 사연과 투표 | "내 동네 가게 사연", 조연 인기투표 |

### 「도달쑤 일일 알바」 구성

**30초 고정 구조**
1. 출근: 실제 장소
2. 사장님의 사투리 한마디
3. 도달쑤의 사고
4. 억울한 표정으로 멈춤 (짤)
5. "오늘의 일당: 납작만두" (실제 음식과 장소)

**회차 예시**
- 서문시장 호떡집: 뜨거운 호떡을 뒤집다 손이 부어오름
- 북성로 공구골목: 렌치를 잘못 건네 사장님이 말없이 볼트만 쳐다봄
- 수성못 오리배: 뚜비에게 노 젓는 법을 배우다 제자리만 돎
- 약령시: 약재 이름을 잘못 외워 손님에게 혼남

**톤 원칙**
- 웃기되 대구 사람을 놀리지 않는다. 사투리는 대구 출신이 감수한다
- 정치적 이미지는 다루지 않는다
- 브레드이발소처럼 처음부터 풍자를 세게 잡지 않는다
- 홍보 문구는 마지막 "일당"에만 넣는다

**대구 이미지의 근거 수준**
- 근거 있음: "무뚝뚝하지만 인정 있다"는 기질 평가(칼럼 수준), 보수적 이미지 논쟁
- 확인 필요: 더위·사투리·치맥을 대구 이미지로 측정한 조사는 못 찾음
- 시 도시브랜드 조사가 11월 22일까지 진행 중 → 결과가 나오면 다시 점검

**→ 따라서** 콘셉트의 중심은 관계이므로, 다음으로 인물을 어떻게 만들지 정해야 한다.

## 5. 인물 설계: 설정 → 에피소드 방식의 점검

### 현재 안 (베리에이션별 설정 → 에피소드)

**장점**
- 대량 제작에 유리
- 설정을 굿즈, 테스트 결과에 재활용

**단점**
- 얼굴이 같으면 소품만으로 성격 차이가 안 보임
- AI 설정은 "밝고 호기심 많은" 식으로 비슷해지기 쉬움
- 설정표에는 갈등이 없어 재미가 나오지 않음

**한계**
- 서문시장 도달쑤와 북성로 도달쑤가 같은 인물인지 불분명
- 회차가 늘면 설정 충돌 관리가 필요
- 도달쑤 변형·수익 이용 가능 여부 미확인

### 수정안

- **순서:** 관계·포맷 → 설정 → 에피소드
- **설정 다섯 칸:** 욕망, 결점, 말버릇, 관계, 금기

**베리에이션 = 같은 도달쑤가 그날 입는 작업복**
- 지금 안: 장소마다 다른 인물처럼 설정 (서문시장 도달쑤, 북성로 도달쑤)
- 문제: 얼굴이 같아 성격 차이가 안 보이고, 인물 수만큼 설정을 관리해야 함
- 수정: 도달쑤는 **한 명**이고, 일터에 따라 옷만 바뀜
  - 서문시장 호떡집 → 앞치마
  - 북성로 공구골목 → 작업복과 렌치
  - 약령시 → 약방 조끼
- 효과: 회차가 늘어도 "그 도달쑤"에 대한 애착이 쌓이고, 옷은 그대로 굿즈 베리에이션이 됨

**회차마다 다른 재미 = 상대 인물이 만듦**
- 도달쑤의 성격은 항상 같음: 눈치 없고 억울한 신입
- 달라지는 것은 함께 일하는 사람
- 예: 도달쑤가 같은 실수(주문을 잘못 받음)를 해도 상대에 따라 다른 장면이 됨
  - 무뚝뚝한 호떡집 사장님: 말없이 쳐다보다 "됐다 마" 하고 호떡을 하나 더 줌
  - 깐깐한 안경집 사장님: 안경을 고쳐 쓰며 실수를 하나하나 지적함
  - 느긋한 수성못 단골: 실수인 줄도 모르고 같이 웃음
- 효과: 도달쑤 설정은 하나만 지키면 되고, 새 가게·새 상대를 넣을 때마다 새 이야기가 나옴

**예시: 납작만두집 사장님**
- 욕망: 줄 서는 가게보다 오래 가는 가게
- 결점: 칭찬을 못 함
- 말버릇: "됐다 마"
- 관계: 도달쑤를 혼내고 몰래 밥을 더 줌
- 금기: 손님 앞에서 화내지 않음

**검증**
- 그림자만 보고 구별되는가
- 이름을 가린 대사로 누구인지 맞힐 수 있는가

**→ 따라서** 관계 상대가 필요하다. 대구에 이미 있는 구별 캐릭터를 활용하는 것이 다음 질문이다.

## 6. 대구 패밀리: 구별 캐릭터 활용

### 왜 좋은가

- 인물이 늘면 관계와 소재가 풍부해짐
- 조연이 역전할 수 있음
  - 쿠로미: 악역 → 반응이 좋아 정식 캐릭터 → 2024 산리오 3위 (헬로키티 5위)
  - 한컴타자 "갈색머리 걔": 인기투표 1위 → 굿즈 출시
- 구별로 지역 애착과 판매처가 생길 수 있음 (`추론`)

### 왜 가족형이 아니라 연합형인가

- **가족형(꿈씨 패밀리):** 한 세계관 안의 혈연·관계, 권리자가 대체로 한 곳
- **연합형(어벤져스, 산리오 캐릭터 총출동):** 각자 독립된 캐릭터가 특정 계기로 모임
- **대구:** 시와 구·군이 각각 권리자이고 이미 따로 활동 중 → **연합형에 가까움**
- **산리오와의 차이:** 형식은 비슷하지만 산리오는 권리자가 하나라 조율이 쉬움. 대구는 그림체와 승인을 맞추는 일이 추가됨

### 어벤져스형 연합의 장단점

**장점**
- **기존 팬 합류:** 각 캐릭터의 지지층을 한곳에 모을 수 있음
  - 예: 스파이더맨 〈노 웨이 홈〉은 이전 시리즈와의 연결로 오랜 팬의 관심을 끎 (국내 758만 관객)
- **각자 설정 유지:** 부키는 북구, 뚜비는 수성구 캐릭터로 남고 억지로 가족이 되지 않아도 됨
- **이벤트 효과:** 평소엔 개별 회차, 가끔 총출동 → "드디어 모였다"는 재미
  - 예: 구별 대항 "대프리카 더위 올림픽" (`추론`)
- **최애 고르기:** 여러 캐릭터 중 고르는 재미가 생기고, 결과가 다음 상품을 정할 수 있음
  - 예: 산리오 순위는 어떤 캐릭터의 상품이 더 나오는지에 영향
- **위험 분산:** 한 구청이 빠져도 전체 기획은 유지 가능 (`추론`)

**단점**
- **진입장벽:** 다 알아야 재미있으면 "공부"가 됨
  - 예: MCU는 "공부해야 하는 프랜차이즈"라는 인식이 생김
- **출연 분량 경쟁:** 구마다 자기 캐릭터가 돋보이길 원할 수 있음 (`추론`)
- **승인 복잡:** 대사 한 줄, 굿즈 하나에도 여러 기관의 확인이 필요할 수 있음 (`추론`)
- **그림체 불일치:** 한 컷에 모이면 제각각인 그림체가 그대로 드러남
- **인지도 격차:** 부키·동구르르를 모르는 시청자에게 "모두 모였다"는 감흥이 약함 → 어벤져스는 각자 단독 작품으로 먼저 인지도를 쌓음
- **과잉 확장:** 작품이 많아지며 질 하락과 억지 연계 문제가 지적됨. 꿈씨 패밀리에도 세계관 피로 우려가 나옴

**대구 적용 원칙**
- 각 회차는 **그 캐릭터를 몰라도 이해되게** 만든다
- 총출동은 개별 회차로 인지도가 쌓인 뒤 드물게 한다
- 그림체는 원형을 바꾸지 않고, 공동 배경과 소품으로 묶는다
- 출연 비중과 승인 절차를 사전에 합의한다

### 그 밖의 현실 제약

- **수익 조율 필요:** 뚜비는 구 직영이고 실적이 있음 (18개월 2.18억 원 `미검증`)
- **굿즈 판매량은 보장되지 않음:** 꿈돌이 실적은 캐릭터 수보다 식품·판매처 영향이 커 보임 (`추론`), 종류가 늘면 재고 부담도 늘어남

### 후보

- **뚜비(수성구):** 망월지 두꺼비, 서브 캐릭터 도리 → 수성못 회차
- **부키(북구):** 수리부엉이, 안경산업특구 → 안경 가게 사장님
- **동구르르(동구):** 팔공산 화강암, 서브 "돌맹이들"은 무리 지어 다님 → 조연 역전 후보, 단 임의 변형 금지 안내 있음
- **달서구:** 자료마다 이름이 달라 보류
- **블레오 패밀리, 리카:** 구단 소유 → 패밀리가 아닌 나중 콜라보로 분리

### 추천 순서

1. **기획 단계:** 해당 지역 회차의 조연으로 넣고 "승인 전 가상안"이라 표시
2. **공개 전:** 구청에 변형, 대사, 상업 이용 가능 여부 확인. 거절에 대비해 우리 소유 조연도 준비
3. **반응 후:** 인기투표로 다음 굿즈 결정
4. **성과가 쌓이면:** "대구 패밀리" 공식 제안

**→ 따라서** 인물이 늘어나도 얼굴과 표정이 흔들리면 안 된다. 제작 방식이 다음 문제다.

## 7. 웹툰·숏폼 장면 이미지 제작

### 왜 파츠인가

- AI에 전부 맡기면 얼굴이 흔들리고 부자연스러움
- AI 웹툰 거부 사례: 낮은 가독성, 이질감, 별점 테러와 보이콧
- 시트콤의 웃음은 **표정 반응**에서 나옴 → 표정이 핵심 자산
- 치이카와 작가도 "반응과 표정"을 그리고 싶다고 말함

### 역할 분담

- **사람:** 얼굴형, 몸, 눈·눈썹·입, 자세, 웃음 포인트, 사투리
- **AI:** 소재와 대사 초안, 컷 구성, 표정·자세 선택, 소품·배경 초안
- **검수:** AI가 그린 소품·배경은 사람이 통과시킨 것만 등록

### 현재 에이전트 기준으로 할 일 (`박민지` 브랜치)

- **이미 있음:** 포즈 4종, 소품 13종, 배경 3종, 얼굴 보호 마스크
- **추가:**
  - 표정 약 12종 (기쁨, 억울, 버럭, 멍함, 당황, 더위에 녹음 등)
  - 자세 8~10종 (앉기, 달리기, 놀람 등)
  - 얼굴을 머리와 분리한 레이어

- **표정은 완성형으로:** 눈·눈썹·입을 자유 조합하면 어색한 얼굴이 나오기 쉬움
- **숏폼 연결:** 파츠로 눈 깜빡임과 입 모양을 움직이는 컷아웃 애니메이션 가능

### 공구 처리 수정안

**경위:** 기본값에 공구골목이 들어가 있어, 다른 요소를 입력해도 공구가 나오는 오류가 있었음. 이를 막으려고 공구를 전면 금지함.

**새 규칙**
- 기본값(입력 없음)에는 공구를 넣지 않음. 기본 장소는 서문시장 유지
- "공구골목", "북성로" 또는 공구를 직접 입력하면 공구 소품 허용
- 다른 장소에는 공구 소품이 나오지 않음

**필요한 수정**
- `BLOCKED_ELEMENTS`의 공구 항목과 관련 지시문 제거
- 공구 소품 추가: 현재 렌치·볼트 그림이 없음
- `DAEGU_SPOTS`에 북성로 공구골목 추가: 어울리는 소품으로 공구를 지정
- 입력 없을 때와 다른 장소 입력 시 공구가 안 나오는지 시험

**→ 따라서** 콘텐츠를 안정적으로 만들 수 있으면, 다음은 시청자를 실제 방문으로 잇는 일이다.

## 8. 유통: 심리테스트 → 관광지 추천

**현재 상태:** 문서상 계획만 있고 구현은 찾지 못함

### 가장 큰 문제: 심리테스트 과부하

- **포화:** 같은 형식의 유형 테스트가 반복되어 관심을 끌기 어려워졌다는 진단이 2020~21년 무렵부터 나옴
- **피로:** "또 무슨 유형이래"로 끝나고, 결과가 비슷비슷해 남는 것이 없음 (`추론`)
- **광고 거부감:** 광고처럼 보이지 않는 테스트의 참여 확률이 약 2배라는 제작사 주장 `발표`
- **차별화 흐름:** 결과를 실제 경험으로 연결
  - 예: 무신사는 진단 결과를 한정판 굿즈로, 프링글스는 결과를 실물 굿즈로 연결
- **한계:** 효과가 얼마나 줄었는지 보여 주는 수치는 찾지 못함

**→ 따라서** "나는 어떤 유형일까"로 내면 또 하나의 비슷한 테스트가 된다.

### 해결: 심리테스트 대신 "알바 면접"

- **형식:** 성격 질문 대신 사장님이 보는 면접 상황
  - 예: "손님이 호떡을 하나 더 달라는데 사장님은 자리를 비웠다. 니는 우얄래?"
- **결과:** 성격 유형이 아니라 **배치받는 일터**
  - 예: "니는 내일부터 서문시장 호떡집 출근이다"
- **이후 행동:** 결과가 곧 실제 코스, 경로, 해당 회차
- **현장 보상:** 방문 QR을 찍으면 "일당" 스탬프, 이후 굿즈 교환 검토
- **다른 테스트와 다른 점 3가지**
  - 콘텐츠 세계관 안에서 진행됨
  - 결과가 실제 장소와 경로로 이어짐
  - 재방문하면 새 일터 배치 가능

### 그 밖의 문제와 수정안

- **성격만으로 여행지를 고르기 어려움**
  - 수정: 면접 문항 4개 + 실용 문항 3개 (동행, 시간, 출발지)
- **초기 고객은 출향민과 2030**
  - 출향민은 대표 명소를 이미 알 수 있음
  - 수정: "처음 왔어요 / 고향 방문이에요" 문항 추가
- **16유형은 제작 부담이 큼**
  - 수정: 일터 6~8곳, 결과 쏠림 사전 시험
- **MBTI 표현의 위험:** 신뢰도 비판, 국내 판권사 측의 도용 주장 사례
  - 수정: MBTI 표현을 쓰지 않고, "재미용" 표시
- **TourAPI 제한:** 무료, 개발 계정 1,000건, 운영 계정 심의 승인
  - 수정: 후보 약 30곳을 미리 받아 저장
- **대중교통 API 조건 미확인:** ODsay는 블로그 글뿐, TMAP은 상품 구매 방식
  - 수정: 동대구역·대구역·반월당 출발 경로를 미리 계산
- **AI 환각:** 없는 장소나 경로를 지어낼 수 있음
  - 수정: 추천은 규칙으로, AI는 캐릭터 말투만 담당

### 수정한 흐름

**7문항 면접 → 배치받은 일터와 함께 일할 캐릭터 → 코스 2~3곳과 실제 경로 → 관련 회차 → 공유 카드 → 현장 스탬프**

**예시 결과: "서문시장 호떡집 배치"**
- 추천: 서문시장 + 근대골목, 반월당 출발
- 연결: 서문시장 호떡집 회차

## 9. 전체 순환과 우선순위

### 순환 구조

1. **숏폼·인스타툰**으로 인물과 관계에 애착을 만든다
2. **표정 짤·이모티콘**으로 일상 대화에 퍼뜨린다
3. **알바 면접 테스트**로 배치받은 일터와 코스를 제공한다
4. **현장 방문**: 회차 속 가게와 장소를 찾아간다
5. **굿즈·식품**: 이미 사람이 오는 곳에서 판매한다
6. **인기투표·사연**이 다음 회차와 굿즈를 정한다 → 다시 1번

### 우선순위

1. **먼저:** 도달쑤 사용 범위 확인, 관계도와 표정 12종, 3회차 테스트
2. **반응이 있으면:** 이모티콘, 구별 캐릭터 협의, 테스트 구현
3. **그다음:** 소량 굿즈, 지역 식품 협업
4. **나중:** 패밀리 공식화, 구단 콜라보

### 시험 지표

- 3회차 저장·공유 비율
- 짤의 2차 사용
- 어떤 조연이 언급되는가
- 테스트 완료 후 코스 저장 비율

목표 수치는 비교 자료가 부족해 첫 3회 결과를 기준으로 정한다.

## 12. 4단계 에이전트 디벨롭 제안

기존 4단계(캐릭터 생성 → 캐릭터 설정 → 관광지 추천 → 굿즈 도안)에 지금까지의 문제와 개선안을 반영한 안이다.

### 바뀌는 큰 틀

- **순서 변경:** 생성 → 설정이 아니라 **설정 → 생성**
  - 이유: 그림이 먼저면 소품이 다른 캐릭터만 늘어나고, 관계와 재미는 뒤에 억지로 붙게 됨
- **공용 설정집:** 네 단계가 같은 인물, 장소, 일터 자료를 사용 → 설정 충돌 방지
- **사람 검수 지점:** 단계마다 사람이 승인해야 다음 단계로 넘어감
- **반응 순환:** 시청 반응이 다음 회차와 굿즈 결정으로 돌아옴

**새 흐름:** 관계·회차 설계 → 장면 이미지 제작 → 알바 면접과 코스 추천 → 반응 기반 굿즈 도안

### 1단계: 캐릭터 설정 → 관계·회차 설계

- **기존 문제:** 베리에이션마다 설정을 만들어 성격이 비슷해지고 충돌함
- **개선**
  - 도달쑤 설정은 하나로 고정, 작업복만 교체
  - 상대 인물을 설정 다섯 칸으로 작성
  - 30초 고정 구조로 대본 생성
  - 컷별 장소, 표정, 자세, 소품까지 출력
- **입력 예시:** "북성로 공구골목, 말수 적은 공구상 사장님"
- **출력 예시:** "컷 4: 도달쑤 / 억울 표정 / 렌치를 든 자세 / 사장님 '됐다 마'"
- **사람 검수:** 웃음 포인트, 사투리, 실제 가게·상인 묘사
- **완료 기준:** 이름을 가린 대사로 인물을 맞힐 수 있음

### 2단계: 캐릭터 생성 → 장면 이미지 제작

- **기존 문제:** 표정이 고정이고 자세가 적음, 공구가 전면 금지됨
- **개선**
  - 1단계의 컷 지시를 그대로 받아 파츠를 합성
  - 표정 약 12종, 자세 8~10종 추가
  - 공구 규칙 수정: 기본값 제외, 공구골목·북성로 입력 시 허용
  - 조연 레이어 추가, 승인 전 구별 캐릭터는 "가상안" 표시
  - AI가 그린 새 소품·배경은 검수 후 등록
- **출력 예시:** 숏폼용 컷 이미지 5장, 눈·입 움직임용 레이어
- **사람 검수:** 얼굴 일관성, 소품 위치, 공구가 다른 장소에 섞이지 않았는지
- **완료 기준:** 공구골목 입력에만 공구가 나오고, 5컷의 얼굴이 동일함

### 3단계: 관광지 추천 → 알바 면접과 코스 추천

- **기존 문제:** 흔한 심리테스트와 비슷하고, 성격만으로는 추천 근거가 약함, 교통 API 조건 미확인
- **개선**
  - 면접 문항 4개 + 실용 문항 3개
  - 결과는 일터 배치, 그 일터의 회차와 코스로 연결
  - TourAPI 자료는 미리 저장하고 사람이 태그
  - 주요 3개 출발지 경로를 미리 계산
  - 추천은 규칙으로, AI는 말투만 담당
- **출력 예시:** "서문시장 호떡집 배치 / 반월당 출발 경로 / 호떡집 회차 / 공유 카드"
- **사람 검수:** 영업일, 현장 정보, 교통 경로
- **완료 기준:** 없는 장소가 나오지 않고, 결과가 한 일터에 쏠리지 않음

### 4단계: 굿즈 도안 → 반응 기반 굿즈 도안

- **기존 문제:** 어떤 굿즈를 만들지 기준이 없고, 권리 조건이 미확인이며, 재고 부담이 있음
- **개선**
  - 반응 좋은 표정과 대사를 후보로 선정
    - 예: 많이 공유된 "억울한 도달쑤"를 스티커로
  - 작업복 베리에이션을 키링 시리즈로
  - 판매 장소에 맞춘 품목: 서문시장 호떡집 편 → 앞치마 키링 (`추론`)
  - 업체 템플릿 위에 제작: 300dpi 이상, 칼선 파일, CMYK 색 변화 확인
  - 권리 승인 여부를 도안 출력 전에 확인
- **출력 예시:** 업체 규격 키링 도안과 미리보기 이미지
- **사람 검수:** 색, 칼선, 글자 뒤집힘, 실제 샘플
- **완료 기준:** 업체 입고 검수 통과, 소량 샘플 제작 가능

### 각 단계의 연결

- 1단계의 컷 지시 → 2단계 이미지
- 2단계의 회차 → 3단계 결과 연결
- 3단계의 공유·현장 방문 데이터 → 4단계 품목 선정
- 4단계의 판매 반응과 인기투표 → 1단계 다음 회차

### 첫 데모 범위

- **장소 3곳:** 서문시장, 북성로 공구골목, 수성못
- **목표:** 3회차로 4단계를 한 번 완주하기
- **구별 캐릭터:** 뚜비를 가상안으로 1회 출연
- **보여 줄 결과:** 대본 → 컷 이미지 → 면접 결과와 코스 → 스티커 도안
